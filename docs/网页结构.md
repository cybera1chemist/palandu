## 公告

公告根据 `data/anoucements.json` 动态加载，并按发布时间从近到远排列。主页的“最近公告”显示最新的两条及内容预览；点击“查看全部公告”或侧边栏“公告”后，在内容区查看完整公告。

公告包含标题、相对发布时间、发布者和正文。正文由段落及带标题的列表项组成。段落或列表文本中以成对 `*` 包围的内容会加粗显示。发布时间以相对时长记录（天、周、月、年），月份按30天参与排序。

`whoCanView` 仅用于前端筛选，不显示给玩家。值为“所有成员”时所有账号可见；也可设为 `{"minimumLevel":"三"}`，表示权限等级达到“三”或更高的账号可见。等级按中文序号比较，“一”最高，序号越大权限越低；未设置等级的账号只可见“所有成员”公告。

## 空间

空间根据 `data/{用户目录}/workspace/workspace.json` 渲染文件夹和文件。网站顶栏和侧边栏由共享导航组件 `assets/components/navigation.html` 与 `assets/js/navigation.js` 提供；主页显示两者，表格预览页只显示顶栏。可打开的 PDF 在新标签页用浏览器原生预览；表格文件在新标签页显示对应 XLSX 内容的 HTML 表格预览。PDF 使用文档图标并显示为红色。

硫磺火的回收站中有一个标题为“？？？？？”的文件，创建者显示为硫磺火。点击后需要输入密码，提示为“那家伙的忌日”；密码是玩家点击文件当天的前一日日期，以月日四位数字（MMDD）输入。密码正确后打开 `sad/sad.html`。

## 消息

### 左边：消息列表
    - 每项里面显示对话的人的头像、昵称和预览对话的最后一条消息
    - 点击列表中不同的项，右边的具体对话也会切换

### 右边：
上面：具体的对话内容
    - 别人说的话在左边，当前登录的用户说的话在右边
    - 别人说的话的气泡框是白的，用户自己说的话是紫色的
下面：发送消息的区域
    - 有文本框和一个发送键
    - 但是这个是伪装的，玩家可以在文本框里面输入文字，但是不能真的发消息

左侧对话列表按 `data/{用户目录}/msg/messages.json` 中的顺序显示；不可打开的条目只显示在列表中，点击不切换右侧内容。默认显示第一条有消息内容的可打开对话。对话记录从对应的 `msg-*.json` 读取，消息通过发送者 ID 判断左右位置。登录用户作为联系人时从账号资料读取信息；非登录用户可在对话记录的 `participant` 中提供昵称和 PNG 或 JPEG 头像路径。文件消息使用文件卡片；点击后弹出下载确认，文件名中的发送者密码线索从账号资料动态生成。普通文本消息直接显示在对话气泡中。user1 打开与萌萌小兔兔（`external-mengmeng`）的对话时，页面原有浅色背景变黑、文字按需变浅，聊天气泡保持原色；切换到其他对话或离开消息版块时恢复。

user1 的萌萌小兔兔对话中，五天前之前的记录初始锁定；输入三位密码后显示，解锁状态按账号和对话保存在浏览器本地。损毁记录为居中的系统提示，图片可点击查看大图，密文文件可通过下载确认保存，破解程序以程序图标卡片显示并打开对应网站。初代炼金术师笔记显示不可预览及模拟下载提示。
