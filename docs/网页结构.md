# 页面列表

## 登录页
玩家在点击网址之后，如果之前没有登录的话，就自动跳转到登录页面；否则，自动登录上次登录的账号，并跳转到主页（index.html）。

## 主页

### nav-bar
最左侧：帕拉恩度的Logo
最右侧：用户头像（圆形）

### 左侧边栏
上方：一些标签（左边icon右边文字）竖着排列下来，分别是：
    主页
    公告
    空间
    消息
    我
下方：icon+”退出登录”

### 右边主要内容区
点击左侧边栏的不同标签后，这边的内容随之改变。
