# 风格样式

## 配色

大部分都使用基础色（就是黑白灰等等，没用色彩的那种），并且以较白较亮的颜色为主。
搭配的彩色：
紫色（#A988B9）：中等
亮蓝色（#80FFFF）：很少
深蓝色（#626BC3）：很少

## 帕拉恩度内部系统

登录页与 `index.html` 展示严格、专制、管理森严的秘密组织内部系统，不采用亲切、柔和的企业产品风格。

- 保留原有浅色基础色和紫色（`#A988B9`）搭配，不对 Logo 做去色处理；亮蓝色、深蓝色只少量用于文件类型等必要区分。
- 使用方正、规整的边框和分隔线建立层级；减少圆角和阴影，避免过度柔和或活泼的视觉效果。
- 导航、回收站、文档和表格图标使用 `assets/icons/` 中提供的 SVG；通过 CSS 尺寸和颜色控制显示，不改动图标造型。
- 保持现有信息架构、数据与交互功能不变；该风格规范不适用于独立彩蛋页面 `sad/sad.html`。
